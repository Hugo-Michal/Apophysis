# Web fractal image set

- 215 validated raster images total.
- 209 came from direct source-image URLs discovered through Google Image Search; 6 came from Wikimedia Commons during the initial search.
- Every image is at least 500 x 500 pixels; the smallest validated size is 512 x 500.
- Search families included Apophysis, Mandelbulber, Mandelbulb3D, JWildfire, Ultra Fractal, Chaotica, Mandelbrot/Julia, and high-resolution square fractal art.
- `google_image_urls.json` contains the deduplicated direct URLs discovered during the Google searches.

The files are intended for local sorting and review. Source-site licensing and usage terms still apply to individual images.
