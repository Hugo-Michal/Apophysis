# Project Agenda

## What this project is

Flame Foundry is a small Flask web application for generating and previewing Apophysis-style fractal flames.

## What it is built for

The project is built to experiment with procedural fractal-flame generation in a simple browser interface. Users can choose a color palette, generate a flame preview, and download the result as `.flame` XML. The renderer is intentionally lightweight and does not aim to reproduce Apophysis pixel-for-pixel.

## Development focus

- Keep the generator outputs varied and visually interesting.
- Keep the web interface simple and usable.
- Preserve downloadable Apophysis-compatible flame data.
- Record every feature change in `features.md`.
